# PDF to PPT Convertor

## 🌐 将网页 Chat 设置为中文 | Set Web Chat to Chinese

你可以将 GitHub Copilot 网页 Chat 界面切换为简体中文。具体步骤请参阅：

- 📖 **[网页 Chat 中文设置指南](docs/set-chat-language-zh.md)** — 详细介绍如何通过修改 GitHub 账号语言、使用页内切换器或调整浏览器首选语言，将 Copilot 网页 Chat 切换为简体中文。
- 🛠️ **[Web Chat 语言切换功能设计提案（English）](docs/web-language-preference.md)** — Proposal for adding an in-page language toggle to the Chat UI, including preference storage (User Settings API / localStorage) and i18n resource selection pseudo-code.
